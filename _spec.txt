1. The Data Ingestion & Integration Layer 
Your system needs to pull messy customer usage and billing data from your B2B clients' 
software in real-time. 
●​ Event Tracking & Data Routing: Twilio Segment 
○​ Why: Segment is the industry standard for Customer Data Platforms (CDP). It 
allows you to ingest data from Stripe (billing) and Mixpanel (product usage) and 
unify it into a single customer profile without writing thousands of lines of custom 
integration code. 
●​ Real-Time Data Streaming: Apache Kafka (or AWS Kinesis) 
○​ Why: For capturing live feature usage (e.g., when a user clicks a button in the 
SaaS app, Kafka processes the event instantly so the AI can react). 
●​ Data Warehouse (Storage): Snowflake or Google BigQuery 
○​ Why: You are processing millions of events across multiple B2B tenants. These 
warehouses are built to run heavy ML queries on massive datasets securely. 
2. The Causal AI & Uplift Modeling Layer (The Brain) 
This is the engine that classifies users into the 4 Quadrants (Persuadables, Sure Things, 
Sleeping Dogs, Lost Causes). You are not doing basic predictive AI; you are doing Causal 
Inference. 
●​ The Framework: EconML (by Microsoft) or CausalML (by Uber) 
○​ Why: EconML and CausalML are open-source Python libraries specifically built 
for "Uplift Modeling". Standard machine learning tells you who will churn; 
CausalML tells you who will change their mind if you intervene. 
●​ Model Hosting: Google Cloud Vertex AI or Amazon SageMaker 
○​ Why: These platforms allow your data science team to deploy Python models as 
APIs securely. 
3. The Agentic Reasoning & Communication Layer (The Voice) 
This layer reads images (for Reverse Onboarding) and negotiates with the user via WhatsApp. 
●​ The LLM (Large Language Model): Anthropic Claude 3.5 Sonnet (via API) 
○​ Why: Claude 3.5 Sonnet is currently the undisputed leader in coding, JSON 
generation, and parsing visual data (e.g., reading a photo of a handwritten 
inventory sheet to configure a database). 
●​ Agent Orchestration: LangChain or LlamaIndex 
○​ Why: These frameworks allow the LLM to use "tools" (like querying the Value 
Vault database or triggering the Solana payment API). 
●​ Communication Gateway: SleekFlow or Wati API 
○​ Why: You must use verified WhatsApp Business APIs (BSPs). SleekFlow and 
Wati are highly optimized for the Malaysian market and allow you to send 
interactive WhatsApp templates with buttons. 

===== PAGE 16 =====
4. The Web3 & Micropayment Layer (The Secret Weapon) 
This is how the AI autonomously buys and delivers GrabFood or partner rewards without a 
human finance team. 
●​ The Payment Protocol: x402 Protocol 
○​ Why: x402 is an open, internet-native standard built exactly for AI agents. It 
allows your AI to hit an API, receive a "Payment Required" HTTP 402 error, and 
autonomously pay for the reward. 
●​ The Blockchain & Currency: Solana + USDC (Stablecoins) 
○​ Why: You cannot use Ethereum or Bitcoin for RM50 rewards; the gas fees are 
too high. Solana offers 400-millisecond finality and costs a fraction of a cent per 
transaction. Using USDC means the reward is pegged to the US Dollar, so your 
SaaS clients don't have to worry about crypto volatility. 
●​ RPC Infrastructure: Helius 
○​ Why: Helius provides the most reliable developer APIs for Solana to ensure your 
AI's payment transactions never fail. 
5. The Application & Dashboard Layer (The Boss View) 
This is the frontend portal where the B2B SaaS CEO logs in to see the 90/10 Triage Dashboard 
and "Budget Saved" metrics. 
●​ Frontend Framework: Next.js (React) 
○​ Why: Fast, SEO-friendly, and the absolute standard for modern SaaS 
dashboards. 
●​ Styling: Tailwind CSS + shadcn/ui 
○​ Why: Allows you to build beautiful, enterprise-grade charts and alert banners 
extremely fast. 
●​ Backend / API Layer: Node.js (NestJS) 
○​ Why: NestJS is an enterprise-grade framework that handles the webhooks 
between WhatsApp, Segment, the AI models, and the frontend dashboard. 
●​ Hosting: Vercel (for the frontend) and AWS (for the backend). 
Summary: How it Connects (The Data Flow) 
1.​ Segment ingests user data and pushes it to BigQuery. 
2.​ EconML (Python) analyzes the data and flags a "Persuadable" user who hasn't used 
the CRM. 
3.​ Node.js calculates their unused "Value Vault" balance and pings the SleekFlow API. 
4.​ The user gets a WhatsApp message. They tap "Claim Reward." 
5.​ Claude 3.5 Sonnet (via LangChain) receives the intent and triggers the payment 
protocol. 
6.​ The Agent uses Solana Web3.js / x402 to instantly pay for a digital voucher using 
USDC. 
7.​ The voucher is delivered in WhatsApp, and the Next.js Dashboard updates to show the 
CEO: "RM 50 Reward Executed. Account Rescued."

3. UI Elements & Shapes 
To get that modern, high-end feel, avoid sharp corners and harsh lines. 
●​ Corner Radius (Rounding): Use 24px rounding on your large cards, and 16px 
rounding on your buttons. This makes the interface feel like a modern iOS app.

●​ Shadows: Do not use dark, heavy shadows. Use a very soft, diffused shadow on your 
white cards to make them float off the beige background. (Example CSS: box-shadow: 
0px 8px 24px rgba(62, 54, 46, 0.04)). 
●​ Dividers: If you need to separate items in a list (like the VIP Queue), don't use dark 
lines. Use a very faint beige line (#EAE3D9) or simply use whitespace to separate them.
